# small-model-guidance

Standalone DSH plugin bundle: model-scoped guidance sections for the system prompt. Design and conventions follow the DeepSeek Harness plugin contract.

## Agent skills

### Issue tracker

Issues live in GitHub Issues, managed through the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings equal to the role names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
